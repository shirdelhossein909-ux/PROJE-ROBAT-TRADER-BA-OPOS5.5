# ابزارهای عمومی سیستم معامله‌گری خودکار

این پوشه بخش‌های عمومی پروژه است. قوانین راهبرد اصلی اینجا نیست.

| فایل | کار |
|---|---|
| `history_downloader.py` | تاریخچه‌ی کندل‌ها را سال‌به‌سال از متاتریدر ۵ می‌گیرد و برای هر نماد یک ZIP می‌سازد |
| `spread_meter.py` | اسپرد واقعی بروکر را از تیک‌ها اندازه می‌گیرد (میانه و میانگین) و `spreads.csv` می‌سازد |
| `backtest_engine.py` | بک‌تستر روی کندل‌های ۱دقیقه با قفلی که جلوی «دیدن آینده» را می‌گیرد (با یک راهبرد نمونه) |
| `watchdog.py` | نگهبان: اگر ربات بسته شد یا گیر کرد، دوباره اجرایش می‌کند و دلیلش را در پیام‌رسان بله گزارش می‌دهد |

ترتیب استفاده: `history_downloader.py` ← `spread_meter.py` ← `backtest_engine.py`.
پیش‌نیاز: `pip install MetaTrader5 pandas numpy matplotlib`
